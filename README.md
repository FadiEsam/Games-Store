# 🖥️ Computer Store (MVP)

**Computer Store** is a minimum viable product (MVP) front-end web application for an e-commerce platform specializing in desktop PCs, gaming rigs, and computer hardware. This project showcases page layouts, typography, visual hierarchy, and user navigation flows designed for future scalability and full-stack integration.

## ℹ️ Overview
The primary goal of **Computer Store** is to deliver a sleek, lightweight, and intuitive user interface for browsing desktop systems and custom gaming setups. Built with foundational web technologies, the prototype focuses on clean layout structure, responsive components, and fluid user interaction.

---

## ✨ Key Features
- **Home Page (`index.html`):** Features highlighted desktop builds, featured gaming hardware, and dynamic banner sections.
- **Authentication Pages:** Styled sign-in (`login.html`) and sign-up (`register.html`) user interface templates.
- **Responsive Web Design:** Fully adaptable layouts optimized for desktops, tablets, and mobile displays.
- **Structured UX:** Clean component distribution, clear call-to-action buttons, and readable product cards.

---

## 🛠️ Tech Stack
- **HTML5:** Semantic markup for page structure and content accessibility.
- **CSS3:** Custom styling utilizing Flexbox and CSS Grid for layout arrangements, responsive breakpoints, and visual styling.

## 🚀 Getting Started

### Prerequisites
All you need is a modern web browser (e.g., Google Chrome, Mozilla Firefox, Microsoft Edge, or Safari).

### Local Setup
1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/computer-store.git
   ```
2. **Navigate to the project directory:**
   ```bash
   cd computer-store
   ```
3. **Run the project:**  
   Open `index.html` in your web browser.
